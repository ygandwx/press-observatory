# 采集范围与噪音统计

监测中心分开显示已配置定时的来源和当前符合采集范围的定时来源。登记时填写来源类型、具体栏目及公开地址。媒体官网可登记社内动态、集团新闻、融媒动态、发展综述、关于我们、机构公告、媒体矩阵及产品与平台。行业、监管和协会来源需登记具体栏目。旧数据仅在已有同址登记记录、发布主体与栏目结构吻合时沿用。只有首页或无从核实来源时，任务在访问前记录原因。

公开列表优先处理符合栏目主体和编辑动作的文章。采购、招标、中标、更正、询价、招聘及广告等核心事项在标题或路径已能确认时直接过滤。仅在业务动作报道中提到曾经采购，不据此排除整篇。提名和推荐参评不能登记成实际获奖。正文主体、行动及证据不足时可人工复核。

自动入库和 AI 分析可分别关闭。自动入库要求可信且启用的合格来源、已核验原文、已关联媒体、非空摘要和发生日，并要求模型明确判断事件主体为媒体自身、事项在所列正向范围内、达到当前配置阈值，且不存在疑似重复。高分行业或监管动态、日期未知以及模型不可用均保留人工判断。已归档原文再次发现只记重复；其他 URL 的新稿不会因为旧档案同名而永久受阻。

今日和近七日使用系统配置的本地日历日。分母是本来源在时段内作出入库、待审或过滤判断的不同原文 URL。重复发现、失败读取和栏目级拦截另有日志。同条原文只计一次，人工回标会修正该篇噪音判定。恢复待审或确认误判可清除先前的噪音标签。按来源展示噪音篇数、分母、比例及分类，人工反馈动作另计。

近七日有至少 10 篇可判定原文且噪音比例达到 75% 的定时来源，有效频次暂降为每周一北京时间 08:00。频次每天按实际观测重算，原有配置不被改写。编辑可查看依据并手动触发采集。单次回执保留本批次的强排除理由及命中词。重新领取中断任务时沿用已落盘的判断，同一批次内不会把先前的入库或过滤改为重复。
