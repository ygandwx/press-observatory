## 操作顺序

先备份业务库并验证可恢复。在独立恢复库运行迁移并预检，再在正式库执行相同命令。输入为获得授权的本机 JSON 数组。公开仓库只提供程序、核对方法与汇总。为完整名册设置文件权限 0600。

```bash
python manage.py migrate
python manage.py archive_records import /private/archives.json --expected 222
python manage.py archive_records import /private/archives.json --expected 222 --apply
python manage.py archive_records export /private/roundtrip.json
```

写入时以原站 UUID 匹配，首次导入以机构名关联既有记录，保留本地主键与事件、信源关系。整批事务遇到标识冲突即回滚。相同输入再次执行应显示“新增 0，更新 0”。导出按 UUID 排序。比较输入与导出时按 UUID 建立索引，并比较每条完整 JSON 对象。档案导入只修改机构表。

迁移 0004 将阅读组迁为查看人员，将编辑、审核、签发、配置组迁为维护人员。保留账号 ID、密码哈希和操作历史。查看人员可打开媒体档案、分类看板、核心追踪及可见的已批准内容。维护人员可在“账号管理”创建账号和改角色。需退回旧权限体系时，一并恢复更新前的应用和数据库备份。
