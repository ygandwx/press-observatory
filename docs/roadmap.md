# 完整功能交付与验证清单

报业观察站将领导看板、动态中心、媒体档案、监测中心、业态日报和每周简报作为同一次工程交付。编辑和审核人沿着原文、事件和机构核验数据，领导依据同一批已批准事件查看统计和期刊。

| 工作面 | 已实现的用户操作 | 验证依据 |
| --- | --- | --- |
| 领导看板 | 查看期间变化、分布、趋势和重点动态，从卡片或分类进入当时可见的列表 | 两件事件归并后，原链接仍显示两件。归并时的新链接显示一件和两份来源，拆回后仍可复查 |
| 动态中心 | 按日期、类别、机构等筛选，标星、检索、批量审核、导出和查看原文 | 浏览器验证事件编辑与审批。隔离测试覆盖 523 件候选的全范围检索、结果分页、CSV、模型失败和权限撤回 |
| 媒体档案 | 预检及导入名册，维护机构分类和五类渠道，查看时间线与同业对比 | 已验证导入幂等、缺项计算、关注、关联事件与两家机构的对比 |
| 监测中心 | 管理信源与规则，定时或手动投递，在弹窗查看本次各信源的进度与新入库列表，处理失败与巡检、补录动态 | 已用公开官网走通采集与待审。隔离浏览器核对本批新增一件、重试采集零件，独立测试覆盖租约重领、重复链接和三级分流 |
| 业态日报 | 生成、编辑并签发六栏日报，追溯原文和归栏资料，复制、导出与撤销分享 | 已验证空栏、待核归栏、多来源事件、已签发旧稿、PDF 与长图下载 |
| 每周简报 | 按完整自然周生成领导参阅版和业务详版，对比前一自然周并检索历史期次 | 已用隔离样本核对周界、本周与上周的入库数、分组明细、事件原文和历史版本 |
| 身份、数据与运行 | 同源登录，服务端权限与审计，数据库迁移，独立 worker、定时投递、备份与恢复 | CI 从干净检出构建镜像、启动 Compose 并执行冒烟测试。独立恢复库已核对签发稿、来源和审计记录 |

## 实际业务资料与运行验证

| 外部条件 | 已有工程支持 | 取得资料后可核验 |
| --- | --- | --- |
| 正式名册、历史资料及归栏依据 | CSV 预检和事务导入、档案维护、原文链接、待核归栏 | 机构覆盖率、历史数据一致性、地方商业报与晚报的归栏 |
| 受限平台授权 | 按信源配置授权数据接口，缺授权时转人工巡检 | 授权范围内的实际覆盖、更新频次和成功率 |
| 模型端点、凭据及编辑标注样本 | 模型抽取、评分、检索和辅助研判接口，可配置阈值与自动入库开关 | 真实模型误收、漏收、摘要质量和调用成本 |
| 完整自然周的核验事件 | 双版本周报、历史归档和引用快照 | 由业务编辑评阅真实一期周报的结论及依据 |
| 目标 Ubuntu 环境 | Compose、健康探针、定时器及备份恢复命令 | 目标机上的 HTTPS、定时运行、告警与回退 |

工程验证的操作和预期结果见[业务验收场景](acceptance.md)。模块实测记录、数据设计和运维命令见[功能对照](../README.md)、[技术架构](architecture.md)与[运行手册](operations.md)。

各模块、监测八页签和跨角色操作的代码依据、浏览器证据及复跑命令见[完整验收矩阵](verification.md)。
