# 编辑改版功能与验收对照

“此前”对应此次改版前的主线。下表给出操作入口和核对条件。浏览器测试运行在带实际 PostgreSQL、Django、worker 和打包前端的隔离实例。模型分流使用可控的协议替身。部署方可以用自己的真实模型和编辑标注另行评估准确率。

| 项目 | 此前 | 当前行为与核对方法 |
| --- | --- | --- |
| 1 看板四项统计 | 有五个指标，部分缺比较值 | 核对今日新增、机构、待审、自动入库。事件发生量与昨日比较；库存在有昨日或上周同日观测时显示差值，首次观测明确显示缺少基线。 |
| 2 异常提醒 | 按总量波动提醒 | 以当日停休刊、两件机构调整、重点媒体经营承压样本逐类验证，点击提醒核对依据事件。 |
| 3 分布下钻 | 有图表和分类导航 | 通过事件类别、机构品类、地区分布进入原快照的筛选列表。核对数量与图表一致。 |
| 4 趋势 | 已有时间窗口 | 切换 7、30、90 天，核对横轴与入库日期。 |
| 5 重点动态 | 显示六件 | 重点区最多三件，看板提供当期日报入口。 |
| 6 AI 占比 | 已有 | 核对当日自动入库数、分母与百分比；空分母单独呈现。 |
| 7 动态筛选 | 八类与重要度已有 | 八类、重要度、趋势标签、关键词可组合。实时与冻结结果均可核对。 |
| 8 事件详情 | 有标题、来源和部分审计 | 核对机构、事件类别、重要度、日期、摘要、来源、录入及审核信息。 |
| 9 收藏关注 | 仅运营人员可写 | 两个社领导账号可分别收藏同一事件、关注同一机构。切换账号检查个人关系隔离。 |
| 10 导出与批量 | 有 CSV 与批量选择 | CSV、Excel 工作簿、当页勾选、全筛选结果和零结果共用访问范围。检查文件内容和总数。 |
| 11 来源与推荐 | 有人工核验 | 失效链接标灰；检查按同机构或同类返回的已批准事件，排除当前项与归档项。 |
| 12 接口状态 | 有加载与失败提示 | 断开接口后查看错误提示，恢复接口后重试；零条显示空态。 |
| 13 分类 | 已有 | 筛选一级、二级、垂直领域、行政层级及关注等级，核对总数。 |
| 14 五类渠道 | 已有 | 查看官网、客户端、官方公众号、视频号、海外账号及待补项。 |
| 15 变化时间线 | 有时间线 | 机构详情按时间查看停刊、改版、合并、矩阵上线及负责人变动等节点。 |
| 16 同业指标 | 原有并排基本资料 | 同品类三家对比发行量、营收、用户量。编辑登记数值、单位、统计日期和来源，缺资料显示待补。 |
| 17 计数和分页 | 有快照及总数 | 检查看板下钻、筛选、分页总数及归档后的实时列表。 |
| 18 信源管理 | 有增改、启停、任务记录 | 栏目核验、启停原因、软移除、最近状态、条数与错误可复查。 |
| 19 关键词 | 有表单及命中数 | 回车提交关键词，绑定机构品类和事件类型，刷新验证。核对采集命中次数。 |
| 20 审核 | 已有版本检查、批审及原文核验 | 在队列展开编辑并核验原文。退回需原因，可记录噪音类型。缺真实核验原文或命中硬排除时不能批准。 |
| 21 策略 | 已有阈值和自动开关 | 分别切换 AI 与自动入库，保存高低界线，核对灰区与低分分流。 |
| 22 覆盖度 | 已有机构覆盖和任务计数 | 检查品类实采数与每日目标、失败来源、最早待审、各来源当日及近七日噪音率和原因。 |
| 23 补全任务 | 已有 | 从五类渠道待补清单打开对应机构，保存后核对缺项减少。 |
| 24 AI 辅助录入 | 已有抽取表单 | 粘贴 URL 或正文提取，复核后提交，详情可追溯录入方式；缺模型或命中噪音显示原因。 |
| 25 日报报头 | 已有 | 生成与签发后查看日期、星期、期号和签发人。 |
| 26 结论与重点 | 已有 | 看一句话结论及最多五项按重要度排列的变化。 |
| 27 分类与专项 | 已有 | 六栏日报、每栏最多两条、有依据的归栏及停刊、合并、机构改革清单。 |
| 28 数据快照 | 已有 | 通过日报生成时的本期、本周、机构、待审计数和页脚核对来源口径。 |
| 29 日报操作 | 已有编辑和发布流程 | 核对生成、保存、复制、PDF、长图、签发、分享、撤销、归档。生成耗时按实际隔离规模单独测量。 |
| 30 周报 | 有独立入口和双版，需手动生成 | 按已结束的自然周生成私有草稿，人工签发。两种阅读版有各自深链接与导出视图，归档期次保留签发依据。 |
| 30a GEO 入口 | 缺 | 打开 GEO 专题，检查时间线与原事件详情相同的事件编号。 |
| 30b GEO 筛选 | 缺 | 按媒体与事件类别组合筛选。 |
| 30c GEO 关键词 | 缺专题判定 | 校验 GEO、生成式引擎优化、大模型优化、AI 可见度、可信传播、智能体检索优化，同一事件仍保留常规分类。 |
| 30d 周报 GEO | 缺 | 周报显示期内 GEO 进展与原文，对无进展的自然周显示空态。 |
| 31 角色 | 有两角色，称谓和个人操作权限需改 | 迁移原分组并保留成员。社领导可阅读、导出、收藏关注；运营编辑管理内容、审核、签发与配置。后端独立鉴权。 |
| 32 审计 | 原有部分操作记录 | 在事件详情核对采集方式、录入人、审核人和时间、退回原因及结构化判定。旧数据缺少可核依据时显示未知。 |
| 33 移动端 | 有自适应，表格断点需扩展 | 在 375、768、1440 像素检查导航、表格、图表、专题和报表。小屏保留可访问的操作及文字。 |
| 34 标签容错 | 有部分回退 | 用未知事件类型、空标签和空列表验证详情、卡片、分布及专题可正常渲染。 |

## 降噪验收

| 项目 | 核对方法 |
| --- | --- |
| N1 采购 | 以人工标注的已入库样本为分母。抽取不足 50 条时给出真实样本数；空库不能计算准确率。旧内容归档与新采集质量分别验证。 |
| N2 排除证据 | 同时测核心采购公告、正文采购公告、招聘公告、广告和第三方新闻。检查被过滤的位置、命中词、来源和时间。真实平台上线仅提及历史采购时保留候选资格。 |
| N3 双命中 | 媒体主体配合有效动作；仅有动作、仅有媒体发布渠道或栏目自定义词时不可放行。负责人任免与招聘分别覆盖。 |
| N4 模型判定 | 在隔离接口检查主体、性质、0–100 分、噪音标识、原因及依据。接口中断和无效输出仅使通过规则的候选进入人工队列。 |
| N5 阈值 | 修改两道分界并查看低分、灰区、高分结果。检查媒体自身、可信来源、真实原文、关联机构、去重与开关；行业或政府主管部门高分仍由编辑审核。 |
| N6 噪音报告 | 使用逐条判定及人工回标核对来源分子、分母、原因和排名。近七日至少十篇且噪音占比达到 75% 的信源按周调度。 |

历史清洗与整批归档有独立的预览、摘要校验和撤回命令。线上数据、逐条清单与备份由部署方私下保管。复跑命令见[运行手册](operations.md)。
