# 报业观察站 · Press Observatory

全国纸媒业态观测平台，追踪媒体机构自身的改革、融合、经营和渠道变化。读者从看板进入事件与机构档案，编辑维护来源、核验动态并生成可追溯的日报与周报。

## 功能对照

| 模块 | 原站实测 | 交接文档要求及复刻范围 |
| --- | --- | --- |
| 领导看板 | 5 个可下钻指标、八类入口、研判空态、重点动态、分布与趋势区 | 今日入库、待审、机构、重点追踪、自动入库占比；对比前期、变化提示、7/30/90 天趋势与日报入口 |
| 动态中心 | 分类带入筛选条件、普通及 AI 搜索入口、标星、详情、来源状态和关联档案 | 事件分类、机构/地区/日期等组合条件、分页、收藏、语义检索、批量审核和导出 |
| 媒体档案 | 主管主办单位、级别、领域、五类渠道、缺项、机构历史 | 三级分类与关注等级、官网/客户端/公众号/视频号/海外账号补全、变化时间线与同业对比 |
| 监测中心 | 采集概览、覆盖度面板、信源配置、关键词管理、自动入库设置、人工巡检、待审核队列、动态录入八页签；概览日志与阈值选项 | 手动/定时采集、可重试任务、主体词与动作词双命中、排除词、三级分流、退回原因、AI 链接或正文录入 |
| 业态日报 | 日期、期号、草稿/签发状态、一句话、关键变化、分类摘要、专项和数据快照；复制、分享、编辑等入口 | 生成与编辑、五条关键变化、签发快照、历史、复制全文、PDF/长图、可撤销的只读分享 |
| 每周简报 | 最新期、历史、搜索及状态筛选 | 领导参阅版与业务详版使用同一批可溯源事件，按完整自然周生成 |

原站实测指浏览可见页面和导航；写入、签发和采集按钮的存在只证明有相应入口。生产内容来自部署方核验的资料。原平台名册、日志数量和 AI 标签均不作为新库初始数据。

## 业务决策

- 卡片和列表共用时间字段、可见范围及筛选条件。日期按北京时间计算。
- 一件行业事件可以包含多篇来源。同一篇报道的多个渠道保留出处，审核人可归并或拆回。
- 阅读、编辑、审核、签发分别授权。领导阅读已批准事件和签发稿，后台同时校验每个写请求。

## 已实现并验证

启动步骤、账号初始化、公开信源导入、模型配置、定时器和备份恢复命令见[运行手册](docs/operations.md)。前端位于 `frontend/`，后端及独立 worker 位于 `backend/`，Ubuntu 定时器位于 `deploy/`。

最初的仓库只含准备文档和链接检查脚本。它覆盖了架构选型和三个业务决策，缺少六个业务模块、可启动环境、数据迁移与功能验证。当前分支包含应用代码、数据库迁移、依赖锁文件、Compose、CI 检查定义及以下验证记录。

| 模块 | 本地验证证据 |
| --- | --- |
| 领导看板 | 浏览器内批准一条真实候选后，“今日入库”从 0 到 1。自动化测试核对八类总数及带截止时间的下钻；后批准的动态不混入之前的查询窗口。 |
| 动态中心 | 浏览器编辑候选的发生日、分类及摘要，审核后出现审计记录。接口测试覆盖收藏隔离、多来源归并/拆回、退回原因、批量事务回滚和 CSV。 |
| 媒体档案 | 浏览器对比两个来自公开资料的机构，看到各自已补渠道数；测试验证档案更新、缺项计算和关联事件下钻。 |
| 监测中心 | 浏览器逐个打开八个页签；通过独立 worker 从光明网“报网动态”读取 30 个候选链接，1 条命中并进入待审。任务重试、缺授权转巡检、模型不可用以及三种分流结果在隔离测试中覆盖。 |
| 日报 | 浏览器生成、编辑、取消、签发、分享、撤销，并实际下载 PDF 与 PNG。独立 PostgreSQL 恢复库核对签发版内容、原文地址与审计记录。 |
| 周报 | 浏览器验证历史列表、筛选和空态；测试库验证按完整自然周选取事件及原文，重复生成沿用同一期次。两个阅读版本共享签发快照。 |

技术验证使用 PostgreSQL 18、Django 5.2、Node 24 和 TypeScript。执行了数据库迁移、后端测试、前端生产构建、文档链接与 Compose 配置校验。看板和日报在 375、768、1440 像素视口测量均无整页横向溢出。模型接口的自动化测试使用隔离替身，真实采集验证使用公开官网。

## 受外部条件限制

- **原有名册与历史数据**。本次提供的资料中没有交接文件所列 CSV。默认库为空，可选择导入有公开出处的两个机构，或通过 CSV 导入经核验的完整名册。
- **模型**。语义检索、辅助录入、研判、评分接口已接入可配置模型协议。尚未使用部署方的真实模型凭据实测质量。自动入库策略默认关闭。
- **授权渠道**。公众号、微博、头条、百家及短视频支持按信源配置授权数据接口，缺配置会进入人工巡检。尚未使用这些平台的真实授权账号验证。
- **正式周报**。生产环境需积累完整自然周的已核验资料，再评价双版本周报的内容质量。一次公开信源采集不能证明长期覆盖率。
- **上线**。本地验证使用独立 PostgreSQL、Gunicorn 和浏览器。生产域名、HTTPS、Ubuntu 定时器常驻与运维告警须在目标机器验证。
