# 报业观察站 · Press Observatory

全国纸媒业态观测平台。跟踪媒体机构自身的改革与业态变化，保留每条观察的出处，为编辑提供采集和核验工作台，为读者提供可下钻的看板、机构档案、日报和周报。

**项目状态**　开发准备阶段。当前仓库提供设计基线、协作规范与项目检查工具。应用启动命令将在 M1 合入时提供。

## 第一条交付链

同一报社的官网和数字报刊登同一项机构改革。采集得到两份原文，编辑核验后归到同一个事件。入库使看板增加一件，点击卡片可以看到对应事件和两份出处，机构时间线也随之更新。签发人将其收入日报，后续来源更新时仍能还原当期内容。

首版以 Ubuntu 单机自托管为部署目标。React、TypeScript 和 ECharts 提供交互界面，Django 及 PostgreSQL 承载编辑业务，独立采集进程与网页服务共用业务规则。首个可试用版本以走通上述链路为准。

## 检查项目文档

在仓库根目录使用 Python 3 运行以下命令，检查仓库文档中指向本地文件的相对链接。

```bash
python3 scripts/check_docs.py
```

仓库用于公开的代码、设计和匿名化测试材料。真实采集正文、导入名册、账号配置与数据库备份保存在部署方控制的存储中。
